## About the Project

**Gradely** is a modern, client-side academic dashboard for tracking grades and forecasting outcomes. It runs entirely in your browser using local storage—no account or backend required.

---

## Key Features

- 🔒 **Local & Private**: All data is stored in your browser's `localStorage`.
- ⚡ **Fast & Responsive**: Built with Next.js and Tailwind CSS for instant interactions.
- 📊 **Grade Forecasting**: "What-if" scenario calculator to plan your success.
- 🎨 **Modern UI**: Clean "Swiss-style" design with a bento-grid layout.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Components**: Radix UI / ShadCN

---

## 🚀 How to Run

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
